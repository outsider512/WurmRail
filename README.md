# WurmRail

Build railways and run steam trains in Wurm Unlimited. Use the latest release to download the server mod and client model pack.

[Download WurmRail](https://github.com/outsider512/WurmRail/releases/latest)

The current release pairs the **2.30.3 server** with the **2.30.2 client**. Both ZIPs include a Quickstart and a Windows installer.
