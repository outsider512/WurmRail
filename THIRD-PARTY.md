# Third-party software

WurmRail is a server mod for Wurm Unlimited. Wurm Unlimited, its game data,
`server.jar`, and `common.jar` are proprietary software owned by their respective
rightsholders. Obtain them through your own licensed installation. They are
compile-time dependencies and are excluded from the WurmRail distribution.

The mod uses the public WurmServerModLauncher API by ago1024 and contributors:

- Project and upstream notices: <https://github.com/ago1024/WurmServerModLauncher>
- Release used for this build: v0.47
- Optional installer download:
  <https://github.com/ago1024/WurmServerModLauncher/releases/download/v0.47/server-modlauncher-0.47.zip>
- SHA-256 of that archive:
  `293554a85cee915585c46f1129609bfa01165b319b81ff7ef3bfffa1b24f8aac`

Consult the modloader project for its upstream terms and notices. Its distribution
includes Javassist, which has its own license options; see
<https://github.com/jboss-javassist/javassist> for the upstream notices and
licenses. WurmRail does not bundle these third-party binaries in its release.
The optional server installer retrieves the original modloader archive, verifies its
SHA-256, and installs only its launcher/runtime files. It does not enable the
example mods included in that archive.

Custom models use the public WurmClientModLauncher API by ago1024 and contributors:

- Project and upstream notices: <https://github.com/ago1024/WurmClientModLauncher>
- Client release used for this build: v0.15
- Optional client installer download:
  <https://github.com/ago1024/WurmClientModLauncher/releases/download/v0.15/client-modlauncher-0.15.zip>
- SHA-256 of that archive:
  `9d19936c8a35bc3c557caba0474b6945bb7bbadd126e23fc133a0accbf6fbb49`

The optional client installer downloads the original official client loader,
checks its hash and runs its official patcher. No client loader, Javassist,
game JAR, or other third-party runtime binary is bundled in the release.

The COLLADA models in `client/packs/wurmrail-models.jar` are original
WurmRail meshes generated by `tools/generate_models.py`: locomotives, wagons,
eight-direction track, junctions, stations, signals and industrial equipment,
including the Log Car, Steam Yarder, Log Bunk and Steam Water Pump. Its color textures
are also original generated PNG assets. No Wurm game models, meshes or textures
are redistributed. Vehicle template icons use resources
already present in each player's licensed game installation.

The mineral Coal item references the native coal/charcoal model and icon from
the licensed installation; those game assets are not redistributed. Vanilla
charcoal remains its original template and identity.
